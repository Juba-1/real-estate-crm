# DEERAH — Office Administrator Guide

Short guide for the person who manages one real-estate office inside DEERAH.

## First day

1. Sign in with the **username** and password provided by the platform operator.
2. Open **Company Settings** and upload your office logo (optional).
3. Open **Admin** and create agents (username + password — letters/numbers only for usernames).
4. Share each agent’s username and password securely.

## Daily work

| Task | Where |
|------|--------|
| See office performance | Dashboard |
| Manage team / reset passwords | Admin |
| Company logo | Company Settings |
| View all listings (no owner phones) | Search |
| Office reports / CSV export | Reports |

## Important rules

- **Owner phone numbers stay confidential** — they appear only on an agent’s own listings, not in Search.
- **Urgent** highlights one listing or request per agent for 7 days.
- Deleting a team member can remove their listings — prefer role changes when possible.
- You cannot delete the **last admin** of the office.

## Notifications

- In-app bell: new listings, requests, urgent items, opportunity matches.
- Browser push (Chrome/Edge): enable the bell icon in the header. On iPhone, install the site to the Home Screen first.

## Need help?

Contact your platform operator (the DEERAH system owner who created your company).
