# DEERAH — Agent Guide

Short guide for listing agents.

## Sign in

Use the **username** and password from your office admin (not necessarily an email).

## Core workflow

1. **Add property** — fill public details, maps link, photos, then confidential owner details (only you and admins see owner data).
2. **My Properties** — edit, change status, delete, mark urgent.
3. **Search** — browse office listings (owner contacts hidden — call the listing agent).
4. **Requests** — post what a client wants; renew within 14 days or mark executed / archive.
5. **Dashboard** — your personal stats.
6. **Reports** — your detailed listings (admins see the whole office).

## Tips

- Use **Google Maps** link when possible — it improves matching quality.
- Watch the **Live opportunities** panel while typing — strong matches appear before you save.
- After save, colleagues may get an opportunity notification if the match is strong.
- Prefer Arabic UI for the clearest product copy.

## Push notifications

Enable the push bell in the header (Chrome or Edge recommended). If push is unavailable, the in-app bell still works.
